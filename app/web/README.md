# app/web: Stream Sarthi streamer app, moderator console, safety report

Next.js 16 (App Router, webpack build) + React 18 + Tailwind 3 + TypeScript (strict). Mobile-first,
English UI with Hindi labels (`lib/i18n.ts`, EN / हिं toggle). Spec: `docs/specs/app-web.md`.

## Run (inside WSL, Node 20+)
    cd app/web && npm ci
    npm run dev        # http://127.0.0.1:3000 (API expected at NEXT_PUBLIC_API_URL, default http://127.0.0.1:8000)
    npm run build && npm run lint && npm run typecheck && npm test

## Layout
- `app/(streamer)/live` real (T1.6): HOLD button, status chip, alert feed. `go-live`, `enrol`, `controls`, `app/(mod)/mod`,
  `app/(report)/report/[sessionId]` are still placeholders
- `lib/hold-machine.ts` pure HOLD state machine and H-key rule; `lib/live-state.ts` alerts (cap 200) and chip; `lib/ws.ts`
  realtime client (auth first, backoff, no leaked handlers); `lib/api.ts` REST; `lib/auth.ts` token (fragment -> memory + sessionStorage)
- `components/streamer/*` (HoldButton, EngineChip, AlertFeed, LiveDashboard), `components/ui/{switch,toast,toaster}` (shadcn, by hand)
- `components/ui/*` shadcn copies from PrivaStream (Apache-2.0, headers kept, `LICENSE.privastream`)
- `components/shell/*` header, language provider, placeholder body
- `lib/wire.ts` typed mirror of `contracts` (types, `decodeWire`, `parseWsFrame`, `TOPIC_TYPES`)
- `lib/i18n.ts`, `lib/config.ts`, `lib/utils.ts`
- `tests/wire_samples/*.json` generated by the contracts, `tests/*.test.ts` vitest

## Type-drift check
Regenerate the samples after any contract change, then run the tests:
    scripts/ss.sh python -m contracts.samples app/web/tests/wire_samples
    cd app/web && npm test
`WIRE_FIELDS` in `lib/wire.ts` is a mapped type: the compiler rejects a missing or extra field, and the test
compares it with the samples and with `contracts/enums.py`.

## Privacy
Never render or store images or raw PII. Alerts show category, time and confidence only. Free-text fields
(`ChatMessage.text`, `CaptionEvent.text`) are shown transiently and never persisted.

## Enrol and controls (T2.5)
- `/enrol`: `components/enrollment/{enrol-panel,camera-capture,face-card}.tsx` (camera-capture and face-card adapted from
  PrivaStream, Apache-2.0). 8 JPEG frames over about 3 s with live guidance (`lib/enrol.ts`, `lib/capture.ts`), sent once to
  `POST /api/enrol`; the camera is stopped and the canvas cleared before the upload; the list shows label, expiry and remove.
- `/controls`: `components/streamer/{controls-panel,category-toggle}.tsx`, state in `lib/controls.ts` (optimistic `PATCH
  /api/config`, rollback on error, confirmation before turning off Aadhaar, PAN or UPI QR).
- `components/ui/{slider,tabs,select}.tsx` hand-written shadcn (slider and tabs on Radix; select is a styled native `<select>`).
- Component tests use jsdom and Testing Library (`// @vitest-environment jsdom`, helpers in `tests/dom-helpers.tsx`).
